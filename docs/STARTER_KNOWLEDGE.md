# ניסיון מהמערכת של המשתמש — מה נשבר ואיך תוקן (לעזרה בהקמת tau-study-starter)

> הקובץ נכתב לתבנית קודמת ופשוטה יותר (tau-study-starter, שרצה ב-GitHub Actions). השיעורים על פנופטו, מודל, Gemini ו-NotebookLM נכונים גם כאן, אבל ההקמה של הפרויקט הזה היא `SETUP.md` ו-`docs/FAQ.md`, לא GitHub Actions.

המערכת של המשתמש רצה סמסטר שלם (2026) על אותם רכיבים: התחברות לאוניברסיטה, פנופטו, מודל, Gemini, NotebookLM, וואטסאפ. אלה הבעיות שקרו בפועל והפתרונות. אין כאן מידע אישי.

## התחברות לאוניברסיטה (SSO)
- הטופס של ת"א (NIDP): שדות #Ecom_User_ID (שם משתמש), #Ecom_User_Pid (ת"ז), #Ecom_Password, וכפתור #loginButton. אחרי הלחיצה צריך לחכות כ-8 שניות לשרשרת ההפניות.
- אותה התחברות פותחת את Panopto, Moodle ו-my.tau. שם משתמש או ת"ז שגויים, או אימות נוסף שהאוניברסיטה דורשת, מחזירים "login failed". מה לבדוק: הסודות TAU_USERNAME, TAU_ID ו-TAU_PASSWORD (בלי רווחים מיותרים).
- ייתכן שהאוניברסיטה חוסמת כניסה מהשרתים של GitHub, שנמצאים בחו"ל. לכן הצעד הראשון הוא setup → feasibility. אם הוא נכשל, מריצים מהמחשב (README → "הרצה במחשב") עם Task Scheduler.

## פנופטו
- שם התיקייה של כל קבוצה מכיל "(<מספר קורס 8 ספרות><קבוצה 2 ספרות>-<שנה>-<סמסטר>)", למשל "(0368200201-2026-1)". סמסטר א' מתחיל באוקטובר ושייך לשנה שבה הוא מתחיל.
- תיקייה מופיעה רק אחרי שעלתה אליה ההקלטה הראשונה. לפני תחילת הסמסטר זה תקין שלא נמצאה תיקייה ("עוד אין הקלטות").
- לא מסננים הקלטות לפי מילה בכותרת. אצל המשתמש הכותרות התחלפו ל"שיעור N" והסינון זרק את כל ההרצאות. מתאימים לפי תיקייה, תאריך ושעה (±90 דקות).
- כתוביות פנופטו הן לפעמים ג'יבריש בקירילית במקום עברית. בודקים שלפחות 20% מהאותיות עבריות, ואם לא, מתמללים.
- הקלטות ריקות של 0–5 דקות קיימות. תמלול של הקלטה כזו החזיר 60 אלף טוקנים של "אוקיי" (עלה $0.15), ולכן מדלגים עליהן.
- שעות: פנופטו מחזיר UTC. שעון ישראל משתנה ב-25/10, ולכן ממירים עם zoneinfo ולא עם הפרש קבוע.

## Gemini
- תמלול: gemini-2.5-flash בלי thinking החזיר ריק (RECITATION), ועם thinking המציא תמלול. gemini-3.8-flash עם thinking נמוך תמלל עברית נכון. זו ברירת המחדל.
- טוקני "thinking" נספרים בתשלום ובתוך max_output_tokens. אצל המשתמש החשבונית האמיתית יצאה פי 3–5 ממה שנרשם, עד שספרו אותם. לתשובות JSON צריך max_output_tokens של 2000 ומעלה, אחרת הן נחתכות.
- "Cannot send a request, as the client has been closed": הלקוח של genai נוצר בתוך ביטוי ונסגר באמצע הקריאה. צריך לשמור אותו במשתנה.
- עלויות בפועל: הרצאה עם כתוביות (25 דקות) עלתה בערך $0.08. בלי כתוביות, 90 דקות, בערך $0.40.
- מפתח: aistudio.google.com/apikey. חובה לשים תקציב ב-Google Cloud Billing, נוסף על התקרה ב-settings.yaml.

## מודל
- עמוד /my/ טוען את רשימת הקורסים ב-JavaScript, אז בבקשה רגילה לא רואים קורסים. משתמשים בקריאת ה-AJAX core_course_get_enrolled_courses_by_timeline_classification (עם ה-sesskey מהעמוד).
- מזהה הקורס במודל הוא מספר הקורס בלי האפסים שבהתחלה ועוד 2 ספרות קבוצה, למשל 368200201.
- לפני תחילת הסמסטר רוב הקורסים מראים עמוד "התראה" (עוד לא פתוחים לסטודנטים). זה תקין, והם ייפתחו לבד.
- מטלות: תאריך ההגשה בעברית ("יום ראשון, 17 מאי 2026, 23:59"). "הוגש להערכה" אומר שהמטלה כבר הוגשה.

## my.tau (מערכת השעות)
- נכנסים דרך מודל, אחר כך לעמוד האישי, לוחצים "ליומן המלא", וקוראים את ה-JSON שהעמוד עצמו טוען (screenservices).
- לכל שיעור יש מספר קורס, קבוצה, סוג (שיעור/תרגיל), תאריך, שעה, בניין וחדר. יש גם "אירועים" עם מספר קורס 00000000, למשל פתיחת שנה, ואותם מסננים.
- לפעמים האתר לא מראה את כל הקבוצות. אצל המשתמש תרגול ההסתברות לא הופיע בכלל.

## NotebookLM
- אין API רשמי. הספרייה notebooklm-py מתחברת עם התחברות Google רגילה (notebooklm login במחשב).
- התחברות שהועתקה מהמחשב לשרת נותקה על ידי Google תוך כיום, כנראה כי ראה את אותה התחברות משני מקומות. בשרת עבד רק login שנעשה על השרת עצמו (דרך VNC).
- לכן ב-GitHub Actions (שרתים שמתחלפים) צפוי ניתוק. הדרך היציבה היא `python -m src.notebooklm` מהמחשב (קודם git pull).
- שגיאת "CSRF token not found" אומרת שההתחברות פגה, וצריך notebooklm login מחדש.

## GitHub
- הסיכומים והחומרים נשמרים ב-repo, לכן ה-repo חייב להיות פרטי (Use this template → Private).
- push נדחה עם "email privacy restrictions": צריך להתחייב עם כתובת ה-noreply של GitHub (Settings → Emails).
- ה-cron של Actions הוא ב-UTC. 19:30 UTC זה בערך 21:30–22:30 בישראל.
- workflow שלא רץ: לבדוק ש-Actions מופעל (בעותק מתבנית לפעמים צריך ללחוץ "Enable"), ושה-permissions מאפשרים write (Settings → Actions → Workflow permissions).

## כללים שהמשתמש למד בדרך הקשה
- סנכרון גיבוי: rclone copy ולא rclone sync, כי sync מחק קבצים שעוד לא עלו.
- YAML עם עברית: רק yaml.safe_dump. גרשיים כמו חדו"א שוברים כתיבה ידנית.
- Word בעברית: alignment=LEFT מוצג בפועל מימין. בודקים לפי קואורדינטות, לא לפי העין.
- כל באג שמתגלה מקבל בדיקה אוטומטית, כדי שלא יחזור.
- תקרת עלות חודשית קשיחה שעוצרת הכול, ולא רק התראה.
